# 🧠 Generador de Briefing Laboral para IA

## 📌 Descripción

Esta es una herramienta web simple que permite estructurar información personal y laboral de una persona para generar un **prompt optimizado** que puede ser utilizado en herramientas de inteligencia artificial como ChatGPT, Claude o Gemini.

El objetivo es facilitar la **orientación laboral**, ayudando a identificar perfiles, fortalezas, restricciones y oportunidades reales de empleo.

---

## 🎯 Objetivo del proyecto

Resolver un problema común:

> “No sé en qué trabajar ni hacia dónde orientar mi búsqueda”

Mediante:

* preguntas guiadas
* estructuración de información
* generación automática de prompt para IA

---

## ⚙️ Cómo funciona

1. El usuario completa un formulario con información personal y laboral
2. Todos los campos son obligatorios (para forzar reflexión real)
3. Al presionar **“Cargar prompt”**:

   * se valida que todos los campos estén completos
   * se genera un prompt estructurado
4. El usuario puede:

   * copiar el prompt
   * pegarlo en su IA favorita

---

## 🧩 Estructura del prompt generado

El prompt incluye:

* contexto del problema
* respuestas del usuario organizadas
* instrucciones para la IA
* formato esperado de respuesta

La IA devuelve:

* perfil laboral
* fortalezas
* restricciones
* nichos recomendados
* trabajos concretos
* plan de acción
* mejora de CV

## 🔐 Principios del diseño

### 1. No romantizar

Las preguntas apuntan a datos reales, no ideales.

### 2. Forzar claridad

Todos los campos son obligatorios.

### 3. Output útil

El prompt está diseñado para obtener respuestas accionables de la IA.

### 4. Simplicidad extrema

Sin backend, sin complejidad innecesaria.

---

## ⚠️ Consideraciones

* La calidad del resultado depende directamente de las respuestas
* Respuestas vagas generan prompts inútiles
* El sistema no reemplaza asesoramiento profesional
